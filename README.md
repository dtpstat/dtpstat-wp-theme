# dtpstat-child

Дочерняя тема WordPress для [dtp-stat.ru](https://dtp-stat.ru) — проекта «Карта ДТП».
Реализует вёрстку по макету `dtpstat-design.fig` поверх родительской темы [Neve](https://themeisle.com/themes/neve/).

## Возможности

- Типографика и палитра по макету (шрифты Roboto подключены локально)
- Донат-блоки: шорткоды `dtp_fund` / `dtp_fund_bar` (сборы через Boosty / Patreon / Tribute)
- Фильтры и поиск в блоге (раскрываются на месте списка)
- Страницы «Команда», «Спонсоры», «Вакансии» — через CPT `dtp_person` / `dtp_sponsor` и шорткоды
- Кроп-размеры изображений `dtp-*` (карточки команды, вакансий, обложки)
- Хедер/меню/футер по макету, промо-карты, SVG-иконки

## Установка

1. Установите и активируйте родительскую тему **Neve**.
2. Скопируйте эту тему в `wp-content/themes/dtpstat-child` и активируйте её.

Тема не требует сборки: PHP/JS/CSS лежат как есть, кэш-версия ассетов задаётся в `functions.php`.

## Товарные знаки

Логотипы Boosty, Patreon, Tribute, Telegram, Instagram и Twitter в `assets/img/`
используются функционально (кнопки-ссылки на профильные сервисы) и принадлежат
их владельцам.
